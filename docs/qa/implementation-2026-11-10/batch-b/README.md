# Batch B – KD-03, KD-08, KD-10

Lokal production build består. 77 målrettede kontroller består: de 70 header-/kontrastkontroller, tekstafstande ved 320/390/768/1440 og forsinkede covers ved 390/768/1440. Før/efter decode har identiske korthøjder og positioner.

Heroens normale højde er fortsat 690 px på mobil og 1000 px på tablet/desktop. Indhold og countdown ligger i flow og kan udvide siden ved brugerdefinerede tekstafstande. Tidsgrupper er separate fleksible spans, så den sidste gruppe ikke bliver afklippet eller blandet sammen med enhederne.

Desktopnav starter x480 ved 1440 på alle hovedsider; CTA er x1210. V2-linkene er flyttet 4,5 px ned til samme optiske linje; headerhøjderne 107/116 er bevaret. `refinement-B.json` og PNG'er er den udførte evidens.
